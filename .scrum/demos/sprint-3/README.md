# Sprint 3 のデモ
## ゴール
スプリントの終わりに、PO はテキスト版の町で「畑を広げる」「税率を変える」を選び、自分の判断で町の推移が変わる様子を見られる。何もしないときの町の推移はゴールデン値のテストで守られ、見えない文字はエラー文の中で見える形で示される。

## 動かし方
```
bash .scrum/demos/sprint-3/demo.sh [コードのディレクトリ] [--rehearse]
```
- コードのディレクトリを省くと、リポジトリの直下のコードを動かす。
- 前提：Godot 4.7.1 が `~/.local/bin/godot` にあること。gdUnit4 が無ければ、場面 0 で `scripts/setup.sh` が導入する（`git`、`curl`、`unzip`、`sha512sum` が要る）。
- 所要時間：1 分ほど（setup が走る場合は、ダウンロードの分が増える）。
- 場面 4 は、`--rehearse` が無ければ標準入力をつないだまま起動する。PO が Enter でターンを進め、番号（1 畑を広げる、2 税率を上げる、3 税率を下げる）でアクションを選び、`q` で終える。何もしない場合との比較は、起動を 2 回に分けて行う。`--rehearse` を付けると、次の 2 つの入力を自動で渡して比べる。
  - 何もしない場合：Enter 6 回と `q`
  - アクションを選ぶ場合：`1`、`2`、`2`、Enter 6 回、`q`
- 場面 4 を単独で動かすコマンド：
  ```
  godot --headless --path <コードのディレクトリ> -s res://demo/text_town.gd
  ```
- 場面 1 は、コードを一時ディレクトリにコピーして、コピーの側で定数を変える。元のコードは変わらない。
- 既知の出力：場面 0 の `scripts/test.sh` の冒頭に、debugger ポートの `ERROR: The remote port number must be between 1 and 65535 ...` と `ERROR: Remote Debugger: Unable to connect to host '127.0.0.1:0'.` が出る。gdUnit4 のコマンドラインの仕様による既知の出力で、不具合ではない。これ以外に ERROR と WARNING は出ない。
- 場面 1 の 2 回目は、意図的に失敗させたテストなので、テストの失敗（FAILED、`Exit code: 100`）が出る。これは台本どおりの出力で、不具合ではない。`demo.sh` の終了コードには影響しない。

## 後片付け
- テストのレポート `reports/` は、`demo.sh` が元から無かった場合だけ、終了時に消す。
- 一時ディレクトリ（場面 1 のコードのコピーと、場面 4 の入力ファイル）は、終了時に自動で消える。
- `scripts/setup.sh` が入れたもの（`addons/gdUnit4/`、`~/.local/opt/godot/`）は、git の管理外のまま残る。不要なら手で消す。
