### 統合した KPT
#### Keep
- Issue の本文を決まったコマンドで最初に読ませる。#29 の作り直しを #33・#35 で繰り返さなかったからである。
- security-review が実際に値を流して測る。読むだけでは見えない欠陥（切り方、処理時間）を見つけたからである。
- 変更の外の警告を分岐元と比べて切り分ける（T3-1）。誤った原因の帰属が0件になったからである。
- extra-review の観点を「計算の正しさ・再現性・検証機能」に絞る。精度を保ったまま最も軽い枠になったからである。
- 同時に走らせる Agent を3つまでにする。中断が0回だったからである。

#### Problem と根本原因
1. **#29 の差し戻し（「全公開関数」のテストの漏れ）**
   - なぜ1：implement が、式を受け取る関数だけを「全」と解釈した。
   - なぜ2：本文を読む前に作り始め、読んだ後も対象を列挙しなかった。
   - なぜ3：`gh issue view --comments` では本文が見えず、見えないときの扱いが決まっていなかった。「全 X」を列挙して数える手順も無かった。
   - なぜ4：経路の表は経路の単位で、受け入れ基準の対象とテストの対応を照合する場所が、報告にもレビューにも無かった。
   - 根本原因：依頼に本文の取得コマンドが無く、「全 X」の基準を列挙表でテストと1対1に突き合わせる手順が無い。
   - 検証：この手順があれば、名前・キーの経路の漏れは列挙表の空欄として報告の時点で見えた。「各アクション」「すべての出力」など、別の基準の漏れも防げる。
2. **T3-2 が効果なし（不変条件に当たる新規の指摘2件）**（前回の根本原因を前提にせず、分析し直した）
   - なぜ1：表は空欄なしだったが、欠陥は表の列が問わない性質にあった。
   - なぜ2：表は「経路ごとに値の形が守られるか」を問う。欠陥は、共通部品の組み合わせ（escape × 切り詰め）の契約と、規模に比例する処理量にあった。
   - なぜ3：不変条件1〜4と表の列6は「長さの上限」だけを問い、上限で切った結果の正しさと、処理時間の上限を問わない。
   - 根本原因：不変条件と表の列に、組み合わせの正しさと処理量が無く、共通部品を契約ごとに確かめる規則も無い。
   - 検証：列があれば、#29・#35 の2件は表を埋める時点で問われた。今後の #34（イベント）や #26（判定）で、条件やイベントの数に比例する処理にも効く。
3. **レビューの依頼の作り方による無駄と誤り（表の転記の誤り、重い再レビュー、一律の extra-review）、および1pt あたりの tokens の増加**
   - なぜ1：#35 の security の再判定に約4.9万、#29 の code の再判定に約6.4万 tokens を使った。#29 の extra-review（約3.4万）は、ゴールデン値のテストと同じ内容の再確認だった。
   - なぜ2：スクラムマスターは依頼を短くしようとして表を書き直した。再レビューは初回と同じ材料で依頼した。extra-review は PBI の内容に関わらず起動した。
   - なぜ3：レビューの依頼に何を入れ、どの範囲を見せ、どの枠を起動するかの規則が無い。T3-2 は「依頼に貼る」としか書いていなかった。
   - 根本原因：レビューの依頼の中身・範囲・起動の条件を決める規則が無い。
   - 検証：規則があれば、3件の無駄（合計約14.7万 tokens、1pt あたり約1.5万）は起きなかった。今後のどの PBI のレビューにも効く。
   - 補足：implement 枠の分析では、小さな PBI ほどレビューの固定費で 1pt あたりの tokens が上がる。この点は、規則で固定費を下げた結果を Sprint 5 で見てから扱う（未対応に残す）。

- **T4-2：経路の表に「組み合わせ」と「処理量」を足し、共通部品は契約ごとに確かめる（T3-2 を置き換える）**（行き先：チーム合意）。全文は `.scrum/agreements.md` にある。効果の確認は、Sprint 5 で列1〜7に当たる新規の指摘0件、処理量を持つ全 PBI で列7が埋まっていることである。
- **T4-3：レビューの依頼は原文を参照させ、再レビューは差分と must に絞り、extra-review は起動する条件を決める**（行き先：チーム合意）。全文は `.scrum/agreements.md` にある。効果の確認は、Sprint 5 で転記の誤りによる再判定0回、再レビューが初回の半分以下、1pt あたりの tokens（振り返りを除く）が 117,815 を下回ることである。
